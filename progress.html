03

Development Timeline

PHASE 01

AMR System Planning

Defined the warehouse navigation concept, robot operating workflow and major system components required for autonomous material transportation.

PHASE 02

Warehouse Map Development

Created a grid-based warehouse map containing the Raw Load area, unloading locations and parking position.

PHASE 03

A* Path Planning

Integrated an A* pathfinding algorithm into the web interface to generate navigation routes between selected warehouse locations.

PHASE 04

Robot Path Commands

Converted the generated grid path into directional movement commands containing movement direction and distance information.

PHASE 05

ESP32 Communication

Established the communication structure between the web interface and the ESP32 for transmitting navigation commands.

PHASE 06

Live Tracking Interface

Added real-time display of robot position, movement distance and system status to the warehouse monitoring interface.

PHASE 07

Navigation Testing

Testing and refinement of robot movement, path execution, distance accuracy and communication reliability are being carried out.

PHASE 08

System Refinement

Current development focuses on improving navigation accuracy, robot tracking, obstacle handling and overall system reliability.
