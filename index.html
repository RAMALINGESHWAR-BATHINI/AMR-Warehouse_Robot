An autonomous mobile robot designed for warehouse material transportation, path planning, obstacle avoidance and real-time monitoring.

01

Project Overview

The AMR Warehouse Robot is an autonomous robotic platform developed to transport materials between designated warehouse locations while navigating through a predefined environment.

The system combines sensors, motor control, path planning and wireless communication to enable the robot to move between warehouse locations and provide real-time information through a web-based monitoring interface.
